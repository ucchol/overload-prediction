# Data

This folder is ignored by version control, so participant data never enter the repository.

Development data. The original study's file, `Updated_Choice_Overload.csv`, one row per respondent, with the chosen option of every file selection trial in columns `ci_co_fl_1` to `ci_co_fl_6` and of every laptop trial in `em_co_lp_1` to `em_co_lp_6`. Pass its path to the experiments or set `OVERLOAD_DATA`.

Confirmatory data. Open datasets, downloaded by the experiment that uses them into `data/external/`.
